Method & scope

LOCAL EXPERIMENT

Training runs on this local server. The side-by-side display replays the original and selected parameters through the real simulation with fixed integration steps. The displayed trajectories are not animations drawn from a preset success path.

Training, validation and test scenarios are separate. Test results are shown only after an explicit evaluation. Checkpoints retain the selected parameters and recorded progress; importing a checkpoint replaces this local demo’s training state.

This experiment adjusts six controller parameters. It does not add semantic understanding, learn from Wikipedia, connect to a wallet or place orders. The public website and its shared controller remain unchanged.
